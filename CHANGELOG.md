# Изменения

## 1.0.3 (2026-11-27)

- Ссылка-приглашение для Discord и других чатов: кнопка «Скопировать ссылку» рядом с кодом комнаты. Одна ссылка на все языки: страница на сайте открывается на языке друга, запускает Phase LAN с уже введённым кодом или предлагает скачать программу. Ссылка гаснет вместе с кодом, когда комнату закрывают.
- Вкладка «Подключиться» понимает вставленную ссылку-приглашение, а о повреждённой ссылке окно говорит прямо.
- Новые игроки ждут в очереди, а не получают «занято»: хост отвечает им по одному в порядке прихода, следующий запрос появляется сразу после ответа, а в окне запроса видно, сколько ещё ждут. Отказ приходит, только если в очереди уже 8 игроков. Кто отменил подключение или пропал из сети, сам выбывает из очереди.
- Гость видит настоящую причину отказа («хост ответил «нет»», «не ответил вовремя») вместо «unexpected end of file».
- Если вход без проверки аккаунта включён, а в мире хоста нет Phase Companion, карточка «Мир» спокойно предупреждает, что лицензионная игра может не пустить друга без лицензии. Ссылка «Поставить мод» ведёт к установке мода.
- Хост на Quilt определяется как Fabric: кнопка «Поставить» ставит ему сборку Phase Companion для Fabric.
- Оформление в игре знает форматы датапаков Minecraft 26.1, 26.2 и 26.3.

## 1.0.2

- Исходный код Phase LAN открыт: [github.com/phase-mc/phase-lan](https://github.com/phase-mc/phase-lan). Установщик собирается в GitHub Actions из тега этого репозитория.
- Установщик правильно узнаёт папку установки, когда Windows записывает путь в коротком виде 8.3 (например, `RUNNER~1`), и не принимает её за чужую.
- Phase Companion скачивается из нового репозитория [phase-mc/phase-companion](https://github.com/phase-mc/phase-companion).
- Установщик: чище нарисован знак луны, ярче текст справа, размер показан как место на диске.
- Друга можно убрать из быстрого входа через открытую комнату.
- Описана политика подписи кода. Версия 1.0.2 не подписана, сверяйте SHA-256; подпись добавим позже.

## 1.0.1

- Коды комнат работают без своего сервера: хост публикует подписанную запись в публичной сети pkarr.

## 1.0.0

Первый выпуск Phase LAN: Minecraft Java Edition с друзьями через интернет, как по локальной сети. Всё в Phase LAN бесплатно.

### Игра с друзьями
- Комната из открытого LAN-мира: хост находит мир сам, а друг подключается по коду комнаты.
- Прямое зашифрованное соединение, а если оно невозможно, то через relay.
- Мир сам появляется у гостя в списке «Локальная сеть».
- Хост решает, кого пустить. Ник привязан к устройству.
- Комната возвращается сама, когда хост заново открывает мир на другом порту.
- Голосовые моды Simple Voice Chat и Plasmo Voice.

### Моды
- Гость получает моды хоста автоматически: с Modrinth или напрямую от хоста. Его прежние моды сохраняются в резервной папке.
- Четыре готовые сборки для Fabric 1.21.1 на вкладке «Моды». Файлы скачиваются с Modrinth и сверяются по SHA-512, а файлы игрока не заменяются.

### Оформление комнаты
- Цветные ники, теги и роли, заголовок в `Tab`, подсветка игроков.
- Phase Companion для Fabric 26.3, Fabric 1.21.1, Forge 1.21.1 и NeoForge 1.21.1 ставится из окна и позволяет собрать больше 8 игроков.

### Окно
- Русский и английский язык. Язык выбирается в меню профиля и меняется сразу, без перезапуска. Пока выбора нет, берётся язык установщика, а затем язык Windows. На нём же говорят трей, уведомления, сообщения комнаты и подписи Phase Companion в игре.
- Новый вид с художественным фоном, тёмная и светлая темы.
- На карточках показано настоящее название мира.
- Ссылки `phase://` открывают подключение, но не подключают без вашего действия.

### Что важно знать
- Установщик пока не подписан, поэтому Windows может показать предупреждение SmartScreen. Сверяйте SHA-256 рядом с файлом.
- Phase не связан с Mojang и Microsoft.
